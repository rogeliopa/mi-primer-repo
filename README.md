# proyecto de practica Git y GitHub

	repocitorio creado  para aprender y
	practicar el uso de Git y GitHub desde la
	terminal en linux.

# ¿para que sirve este ployecto?


	este proyecto sirve para:

	. inicializar repocitorio Git
	. crear , modificar y eliminar archivos
	. usar 'git add' y 'git commit'
	. ver el historial con 'git log'
	. volver al commits anteriores
	. usar 'git reset --soft' , --mixed' y '--hard
	. modificar commits ('git commit --amend')
	. eliminar archivos del repocitorio
	. rescribir el historial de git
	. subir cambios a GitHub con 'git push'
	. resolver errores comunes
